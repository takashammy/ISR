# Inner Soul Record

Style explorations for the Inner Soul Record website. Five full-page homepage directions, same story:

- mini indie label and singer roster
- Dreamin’ Indie community app
- music publishing
- live performances

## View the styles

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

| # | Direction | Feel |
| --- | --- | --- |
| 01 | [Midnight Vinyl](styles/midnight-vinyl.html) | Late-night, gold-on-black listening room |
| 02 | [Paper Zine](styles/paper-zine.html) | Cream editorial magazine |
| 03 | [Cassette Club](styles/cassette-club.html) | Neon poster / tape-deck energy |
| 04 | [Catalog Archive](styles/catalog-archive.html) | Swiss grid, publishing catalog |
| 05 | [Hearth Stage](styles/hearth-stage.html) | House-show warmth |

Artist names in the mockups are placeholders for layout.
